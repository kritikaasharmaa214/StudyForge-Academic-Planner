# Practical development roadmap

StudyForge is a usable initial product, with opportunities for genuine ongoing engineering work:

1. **Automated reminder engine**: due-date alerts and optional notification configuration.
2. **Calendar planner**: reschedule tasks across days while honoring unavailable time slots.
3. **Import/export**: validated CSV/JSON backup and restore with versioned schema.
4. **Rubric-aware grades**: distinguish weighted categories and actual grade policies.
5. **User profiles and auth**: prepare for multi-user deployment with security reviews.
6. **Research-backed forecasting**: collect consented anonymized longitudinal data, train/evaluate a model and publish uncertainty calibration. Do not relabel current heuristic as trained ML.
7. **Accessibility**: keyboard, color-contrast and assistive-tech audits.
8. **Integration tests**: browser automation, API fuzzing, concurrency and migration coverage.

These are planned enhancements, not features claimed to be implemented.
